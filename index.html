VideoScout Agentic QA over long videos
GitHub
Live demo · recorded runs

An agent that searches, looks and verifies before it answers

Instead of stuffing uniformly sampled frames into one model call, VideoScout searches a long video for the moments that matter, looks at them with a vision model, and has an independent verifier check the answer against what it actually saw, all under a fixed tool-call and frame budget.

View source
  1. 01SearchSigLIP 2 frame embeddings + BM25 over subtitles, fused with RRF
  2. 02RecallYOLO26 + ByteTrack tracks, queried with guarded read-only SQL
  3. 03LookYOLOE-26 open-vocabulary detection and a vision sub-agent
  4. 04VerifyFresh-context judge that accepts or sends the agent back
